# 🎓 EduTrack – Student Management System

A simple **Student Management System** built using **HTML, CSS, PHP, and MySQL** that performs full **CRUD operations (Create, Read, Update, Delete)**.

This project demonstrates fundamental **full-stack web development concepts**, including authentication, database management, and a multi-page dashboard system.

# ⚙️ Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/aarya25dh/EduTrack-Student-Management-System.git
```

---

## 2️⃣ Open in Local Server

Use **XAMPP / MAMP / WAMP** and place the project inside the **htdocs** folder.

---

## 3️⃣ Create Database

Create a database called:

```
edutrack_db
```

---

## 4️⃣ Import Database

Import the provided SQL file:

```
setup_database.sql
```

---

## 5️⃣ Run the Project

Open in your browser:

```
http://localhost/EduTrack-Student-Management-System
```
